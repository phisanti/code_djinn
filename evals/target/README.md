# Djinn Sample Service

Project codename: NOVA-HARBOUR.

This dummy service exists only for Code Djinn evaluation. It has a small Python
package, a couple of config files, operational docs, sample data, scripts, and
tests.

Useful search anchors:

- `CALYPSO_MARKER` appears in a formatting helper.
- `NEBULA_TOKEN` is the configured API token environment variable.
- `zeta_index` appears in reporting and event data.
